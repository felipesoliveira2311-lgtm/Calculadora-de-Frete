#🚚 FreteJá — Calculadora de Frete

Projeto desenvolvido para praticar e aplicar conhecimentos de HTML, CSS e JavaScript, criando uma calculadora de frete com uma interface simples, organizada e responsiva.

A aplicação permite que o usuário informe o valor da compra e selecione sua região, realizando o cálculo do frete e exibindo o resultado diretamente na página.

##💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

##🎯 Objetivos do projeto

Este projeto foi desenvolvido com foco na prática de:

* Estruturação de páginas com HTML;
* Estilização e organização de layouts com CSS;
* Flexbox e responsividade;
* Manipulação de formulários;
* Eventos e funções em JavaScript;
* Manipulação do DOM;
* Aplicação de lógica de programação em uma situação prática.

##📚 Sobre o desenvolvimento

O FreteJá faz parte dos meus projetos de estudo em desenvolvimento web. Durante sua criação, trabalhei desde a estrutura e o layout da página até a implementação da lógica responsável pelo cálculo e apresentação dos resultados.

O projeto também foi uma oportunidade de colocar em prática conceitos estudados separadamente e entender melhor como HTML, CSS e JavaScript trabalham juntos em uma aplicação real.
